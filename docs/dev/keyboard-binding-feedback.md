# 键盘绑定等待反馈

选择键盘并点击连接后，GUI 立即在原弹窗中显示设备名称、进度环和“正在连接键盘并读取电量”，等待期间禁止重复连接。托盘仍独占私有协议访问，GUI 不访问 HID。

使用现有设备命令的请求 ID 关联托盘回执。托盘发布 binding → bound / error，GUI 在同一锁下读取请求 ID、状态和消息，仅接受当前请求的完成状态。绑定回执独立于扫描状态，后续扫描、移除不会覆盖结果。新增共享状态字段 keyboard_request_id、keyboard_bind_state、keyboard_bind_message，旧快照缺少时默认为 0 / idle / 空字符串，不修改配置格式。

等待超过 30 秒显示仍在等待的提示，并允许关闭弹窗；关闭不取消后台请求，也不允许重复提交。重新点击新增键盘可查看该请求。完成后关闭弹窗并展示真实设备快照，异常在弹窗中显示并允许重试。

验证覆盖：提交即显示等待、旧回执不结束等待、处理中防重复、成功与异常回执、慢请求可关闭、完成后重开不残留进度环、移除不覆盖回执、旧错误不混入新请求、共享状态兼容。真实键盘的 5–10 秒读取需要硬件验收。
