# 发布流程的打包程序检查

标准产物是 PyInstaller `--noconsole` 单文件 EXE。发布前必须等待 `--smoke-test` 进程退出，并检查该进程自己的退出码；不能把 PowerShell 中可能为空或遗留的 `$LASTEXITCODE` 当作结果。

检查成功后才允许重命名并上传发布文件；检查失败须显示实际退出码并中止上传。检查步骤设两分钟上限，避免进程不退出时无限等待。

回归验证直接执行工作流中的检查脚本，以真正的 Windows GUI 子系统进程覆盖成功、失败、等待完成和遗留退出码。正式验收再补跑 GitHub Actions，确认 EXE 上传完成。

为已有版本补跑时，在 `main` 的最新工作流中传入 `release_tag`。仅发布流程修复的补跑应先确认应用源码相对该标签未改变，保留现有 Release 和标签。
