## 问题修复
- 修复电脑重新开机后，设备已充满电但界面可能继续显示旧电量并提示异常帧的问题。
- 修复异常电量帧或读取失败时更新时间仍被刷新，避免产生电量刚刚读取成功的误判。

## 体验优化
- 优化“刷新电量”：现在会强制读取当前已连接的鼠标、键盘和蓝牙设备，并等待明确的刷新结果。
- 优化 Windows 自动更新流程，更新包校验、安装和重启过程更加稳定。
- 更新说明会按照当前界面语言显示，中文界面与英文界面不再混杂。

## Bug Fixes
- Fixed an issue where a fully charged device could still show an old battery level and an abnormal-frame warning after the computer restarted.
- Fixed an issue where abnormal or failed battery reads could refresh the displayed update time, avoiding a misleading impression that the battery had just been read successfully.

## Experience Improvements
- Improved “Refresh Battery” to force a fresh reading from all currently connected mice, keyboards, and Bluetooth devices, with a clear completion result.
- Improved the Windows auto-update flow with more reliable package validation, installation, and restart handling.
- Release notes now follow the current interface language, preventing Chinese and English content from being mixed.
