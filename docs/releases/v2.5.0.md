## New Features

- Added battery level and charging state monitoring for ASUS ROG dedicated 2.4 GHz and Omni Receiver wireless mice.
- Added device binding and battery monitoring for ASUS ROG direct 2.4 GHz and Omni mechanical keyboards.
- Added accurate online and sleep state detection; offline or sleeping devices display sleep state without stale battery readings and automatically resume upon waking.
- Added ROG brand accent color for clearer card and system tray indicators.
- Modernized GUI visual design with refreshed color palettes, card layouts, and visual hierarchy.

## Experience Improvements

- Enhanced bilingual localization and unified runtime status text translation.
- Updated documentation with structured peripheral compatibility matrices in English and Chinese.
