- Fixed the battery flyout briefly appearing and immediately closing when opening it repeatedly from the system tray.

- Improved the proportions of battery digits and rings, along with light and dark taskbar adaptation, for better tray icon readability.
- Replaced device removal text buttons with close icons while preserving tooltips.
- Added RTSS troubleshooting instructions to distinguish automatic window hiding from browser process crashes.
