## 新增功能
- 点击托盘图标即可打开电量浮窗，集中查看和管理鼠标、键盘及蓝牙设备。
- 支持胶囊电池、竖向电池、纯数字和圆环四种托盘图标样式。
- 新增磨砂通透度调节和当前窗口的自动刷新开关。

## 问题修复
- 改善睡眠唤醒后的鼠标连接恢复，单台设备读取失败时独立重连。
- 设备扫描、绑定和刷新等待实际结果，失败时显示具体原因。
- 缺少 WebView2 运行时时提供官方下载引导，托盘监控继续运行。

## 体验优化
- 更新设备卡片、设置面板和磨砂背景，提高文字与电量数字的可读性。
- 隐藏窗口停止状态轮询，长期闲置时释放界面进程。
- 优化充电时的采样频率，减少部分罗技鼠标电压估算电量的小幅跳动。

## New Features
- Click the tray icon to view and manage mice, keyboards, and Bluetooth devices in a battery flyout.
- Choose capsule battery, vertical battery, number, or circle tray icons.
- Adjust glass transparency and control automatic refresh for the current window.

## Bug Fixes
- Improve mouse reconnection after sleep, recovering failed devices independently.
- Wait for actual scan, binding, and refresh results and display specific failure reasons.
- Provide an official download guide when WebView2 is unavailable while keeping tray monitoring running.

## Experience Improvements
- Refresh device cards, settings, and glass backgrounds for clearer text and battery readings.
- Stop state polling while hidden and release the interface process after prolonged inactivity.
- Adjust polling during charging and reduce small fluctuations in voltage-derived battery levels on supported Logitech mice.
