## 新增功能

- **自定义设备名称**：点击设备卡片右上角的铅笔按钮，为鼠标、键盘和蓝牙设备设置别名。名称会在重启后保留，并同步显示在托盘和低电量通知中；清空名称即可恢复默认。
- **扩展华奋达键盘支持**：不再限制单一接收器型号，采用兼容华奋达方案的键盘可通过“新增键盘”扫描并绑定，实际可用性以协议探测结果为准。

## 体验优化

- **显示 Logitech 真实型号**：首次成功读电后尝试读取鼠标的真实名称；读取失败时保留默认名，已设置的别名继续优先生效。
- **减少 ROG 通信空转**：优化 ROG 鼠标与键盘等待响应时的处理，减少无数据或无关响应带来的 CPU 空转。
- **完善使用说明**：同步中英文设备兼容范围、重命名、低电量提醒和刷新说明，统一采用“华奋达 / Huafenda”称呼。

## 问题修复

- 修复已绑定无线键盘达到低电量阈值时没有系统通知的问题。
- 修复键盘卡片固定显示默认名称、与扫描列表名称不一致的问题。
- 修复部分 Logitech 设备明确返回功能不支持或查询错误后，仍需等待超时的问题。
- 修复离线设备仍可能使用旧电量触发低电量通知的问题。
- 修复单实例保护可能跨 Windows 登录会话互相阻挡，以及权限受限时失效的问题。

## New Features

- **Custom device names**: Use the pencil button on a device card to rename mice, keyboards, and Bluetooth devices. Aliases persist across restarts and appear in the tray and low-battery notifications. Clear the name to restore the default.
- **Expanded Huafenda keyboard support**: Scanning is no longer limited to a single receiver model. Keyboards using a compatible Huafenda solution can be scanned and bound through **Add keyboard**, subject to a successful protocol probe.

## Experience Improvements

- **Actual Logitech model names**: After the first successful battery read, the app attempts to retrieve the mouse's actual name. It keeps the default name if the query fails, and custom aliases continue to take precedence.
- **Less CPU spinning during ROG communication**: Improved response handling for ROG mice and keyboards reduces CPU spinning when no data or unrelated responses arrive.
- **Updated usage documentation**: Refreshed the Chinese and English compatibility, renaming, low-battery alert, and refresh instructions, with consistent **Huafenda** terminology.

## Bug Fixes

- Fixed missing system notifications when a bound wireless keyboard reaches the low-battery threshold.
- Fixed keyboard cards showing a fixed default name instead of the hardware name shown in the scan list.
- Fixed unnecessary timeout waits after some Logitech devices explicitly report an unsupported feature or query error.
- Fixed offline devices potentially triggering low-battery notifications from stale readings.
- Fixed single-instance protection interfering across Windows sign-in sessions or failing when access is restricted.
