## 体验优化

- **添加键盘时显示连接进度**：选择使用私有协议的键盘后，立即显示正在连接和读取电量的提示；等待较久时可关闭窗口，托盘运行期间继续连接，失败时可重试。
- **手动刷新直接读取设备电量**：在面板或托盘菜单中刷新时，重新读取鼠标、键盘和已绑定蓝牙设备的电量，并显示刷新状态。
- **更新下载进度更清楚**：显示下载来源、进度、已下载大小和速度；下载期间可取消，取消或失败后可重新尝试。
- **更新说明跟随界面语言**：使用中文界面时显示中文说明，使用英文界面时显示英文说明。

## 问题修复

- 修复启动或手动刷新时，鼠标新电量与旧记录差距较大便被忽略的问题，避免充电后仍显示旧电量。
- 修复鼠标电量读取失败时仍更新读取时间的问题，保留上次有效读数的实际时间。
- 修复鼠标返回无效负电量时仍保留在线状态的问题，正确提示休眠或连接中断。
- 修复鼠标持续读取失败时，旧电量记录阻止自动重连的问题。
- 修复检查更新提前结束或网络请求长时间卡住的问题；下载停滞或持续低速时会尝试下一个可用来源，最终失败时明确提示。
- 加强更新文件的版本、大小和完整性检查，避免错误或不完整的文件替换当前程序。
- 修复多个更新任务同时运行时争用文件的问题，同一程序目录只允许一个更新任务。
- 修复替换程序未准备好便关闭应用的问题；准备失败时保留当前应用运行。
- 更新替换或新版本启动失败时恢复旧版本，并提示失败原因；同一失败版本暂停自动重试，仍可在设置中手动重试。

## Experience Improvements

- **Connection feedback when adding a keyboard**: Selecting a keyboard that uses a private protocol immediately shows its connection and battery-reading status. If it takes longer, you can close the window while connection continues with the tray app running, or retry after a failure.
- **Manual refresh reads devices directly**: Refreshing from the panel or tray menu reads the battery levels of mice, keyboards, and bound Bluetooth devices again, with visible refresh status.
- **Clearer update download progress**: Shows the download source, progress, downloaded size, and speed. Downloads can be cancelled and retried after cancellation or failure.
- **Release notes follow the interface language**: Chinese interfaces show Chinese notes, and English interfaces show English notes.

## Bug Fixes

- Fixed fresh mouse battery readings being ignored during startup or manual refresh when they differ significantly from previous readings, which could leave an outdated level after charging.
- Fixed failed mouse battery reads updating the reading time. The time of the last valid reading is now preserved.
- Fixed mice remaining marked as online after returning an invalid negative battery level. They now show a sleep or disconnected status.
- Fixed stored mouse battery levels preventing automatic reconnection after persistent read failures.
- Fixed update checks ending prematurely and network requests stalling for too long. Stalled or persistently slow downloads try the next available source and report an error if all attempts fail.
- Strengthened update file version, size, and integrity checks to prevent incorrect or incomplete files from replacing the current application.
- Fixed concurrent update tasks competing for files. Only one update task can run for each application directory.
- Fixed the application closing before its replacement helper was ready. The current application keeps running if preparation fails.
- Restores the previous version and reports the reason if file replacement or the new version's startup fails. Automatic retries are paused for that failed version; manual retry remains available in settings.
